# Sudoku

Numbering games
玩法和規則用傳統的sudoku做法
這是為開發一款簡單但有跟時間賽跑的sudoku apps遊戲
首先設定畫面虛擬座標為高2300，闊1100，即左上角為(0,0),右下角為(1100,2300),即向右是x,向下是y。
sudoku棋盤為一正方形，在以上虛擬座標的(100,500)為棋盤左上角，右下角是在虛擬座標的(1000,1400)，即900x900的正方形
棋盤裏分為9x9格，每格在虛擬座標裏都是100x100。格子編號由(0,0)到(9,9)即左。上角第一格的編號為(0,0),右下角格子編號是（9，9），同樣向右是x,向下是y。
棋盤外圍用粗黑框。而棋盤內共畫分為9個3x3格的大格，亦有黑色粗框。其餘格子是用幼外框。棋盤底色用淺黃色。
預設的數字用深藍色，由玩家填上的數子為黑色。
除了已有預設數字的格子外，其餘格子可給填數字，當點擊格子後，以這個格子的中心為中心點，做出並顯示一個半透明像冬甩的有外框的中空圓形，外圓半徑為100，內圓半徑為50，外圓內圓都有黑框，而內圓範圍內(即半徑50範圍內）是透明的(像冬甩)。然後把這個冬甩平均分9等份，在冬甩的正上方(即12點位置)為第1份並顯示實色黑色1，順時針方向，第2份顯示2，第3份顯示3，如此類推把1至9平均地顯示在這個半透明冬甩範圍內，而中間是空的並能看到點擊的格子數字(或空的沒有數字)。
預設數字操作，在出謎題方面可參考"數獨出題核心類別.md",並幫忙把這個轉化為class/function。
時間方面，顯示時分秒，想create一個圓角的長方形，座標在虛擬座標的(400,200)至(600,400)。邊框厚度為10，中灰色，而邊框以內是黑色，在黑色範圍內顯示時間SS:MM:HH, 顏色用，亮綠色。時間是由00:00:00 count up。
當出完迷題後，只要當玩家在screen上任意地方點擊一下遊戲正式開始，counter亦隨之開始由0count up直到完成為止。
Submit 鍵: 當所有格子填滿，在虛擬座標(300,1600)至(700,1700)會顯示出"提交?"鍵，這鍵有金色粗框，框厚度為5，底色為清綠色，字色為黑色。
"提交?"鍵按下後，時鐘會立即停止count up, 點擊暫停反應，核對有沒有錯(留意可能會出現muliple answer, 如果正確便會成功通關。如果不成功，會有“錯誤”視窗彈出，虛擬座標為(300,700)至(700,900),銀色粗框，框厚度5，底色為紅色，字為黑色粗字, 
如錯誤，玩家可在screen任何位置點擊一下，時鐘會從剛才停止的時間繼續count up, 棋盤回復可修改。
