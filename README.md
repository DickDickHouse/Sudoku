# Sudoku

Numbering games
這是為開發一款簡單但有跟時間賽跑的sudoku apps遊戲
首先設定畫面虛擬座標為高2300，闊1100，即左上角為(0,0),右下角為(1100,2300),即向右是x,向下是y。
sudoku棋盤為一正方形，在以上虛擬座標的(100,500)為棋盤左上角，右下角是在虛擬座標的(1000,1400)，即900x900的正方形
棋盤裏分為9x9格，每格在虛擬座標裏都是100x100。格子編號由(0,0)到(9,9)即左。上角第一格的編號為(0,0),右下角格子編號是（9，9），同樣向右是x,向下是y。
當點擊格子後，以這個格子的中心為中心點，顯示一個半透明像冬甩的有外框的中空圓形，外圓半徑為100，內圓半徑為50，外圓內圓都有黑框，而內圓範圍內(即半徑50範圍內）是透明的(像冬甩)。然後把這個冬甩平均分9等份，在冬甩的正上方(即12點位置)為第1份並顯示實色黑色1，順時針方向，第2份顯示2，第3份顯示3，如此類推把1至9平均地顯示在這個半透明冬甩範圍內，而中間是空的並能看到點擊的格子數字(或空的沒有數字)。
